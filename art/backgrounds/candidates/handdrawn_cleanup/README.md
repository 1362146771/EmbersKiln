# 手绘强化处理版

本目录保存已批准的36张处理源图；现行场景资源已实装，历史背景参考版本同步更新并保留其参考用途。`index.html` 可查看处理前后对照，旧图仅存于临时工作目录；`manifest.json` 记录输入哈希、生产映射与尺寸。

使用内置 image_gen 逐图编辑；当前风格保留原构图、配色与角色身份，强化墨线、水粉色块和笔触，减少细碎纹理。

背景按完整场景处理，保持不透明，未拆成透明地景。覆盖16张背景/旧版及20张四级建筑院落。院落保持角色数量、建筑等级、镜头与功能道具；城镇分层底图保留5处建筑空地。院落1536×1024，竖版背景保持原宽高比，部分输出分辨率提高至941×1672。
