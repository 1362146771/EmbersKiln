# 手绘强化处理版

本目录保存已批准并实装的25张处理源图，正式映射以 `art/enemies/manifest.json` 为准。`index.html` 可查看处理前后对照，旧图仅存于临时工作目录；`manifest.json` 记录输入哈希、生产映射与尺寸。

使用内置 image_gen 逐图编辑；当前风格保留原造型、姿态、配色，使用有粗细变化的墨线、水粉色块和简化纹理。

怪物使用1254×1254真实透明画布，保留原图占比；匣母5状态脚底边缘差数像素。釉裂兽（Glazemaw）与熔岩幼兽（Magmawhelp）经用户批准沿用原图。10张 Escort 沿用既有已批准的独立手绘版本。
