# 战斗牌堆图标

当前资源：`ICO_DrawPile_v2.png`（抽牌堆）、`ICO_DiscardPile_v2.png`（弃牌堆）。均为内置 image_gen 生成的透明 PNG，粗墨线、低饱和二分明暗。米白红色窑印叠牌表示抽牌，板岩蓝旋纹错叠牌表示弃牌。

生成提示规范：独立叠牌 UI 图标，方形透明背景，三分之四视角、略倾斜、厚纸边、简洁手绘地牢漫画风，缩小到图标大小仍可辨；图中不含文字、数字或数量角标。抽牌使用米白牌面、暗赭红窑火图案；弃牌使用蓝色牌背、浅蓝灰烬旋纹及三张错开的牌。

数量由场景中的红色圆形角标实时显示，不画在图片里。`DrawPile.tscn` 和 `DiscardPile.tscn` 使用透明无底板布局；图标与角标不拦截父控件点击，保持只读浏览入口。主动拖拽弃牌已按用户 2026-09-18 要求移除，原普通出牌、回合末弃牌与洗牌规则不变。
