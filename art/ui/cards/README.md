# 卡牌类型装饰框

当前正式资源由内置 image_gen 生成，原图为 1024×1536 RGBA；中心与框外透明。Godot 导入限制长边 192，九宫格边距 28，避免随卡牌高度拉伸角饰。原图保持完整分辨率。

| 类型 | 文件 | 配色与轮廓 |
|---|---|---|
| 攻击 attack | FRAME_Attack.png | 暗赭红、尖角铁护片 |
| 技能 skill | FRAME_Skill.png | 板岩蓝、圆整铁包角 |
| 能力 power | FRAME_Power.png | 暗琥珀、弧形铁包角 |
| 状态 status | FRAME_Status.png | 灰紫、缺口护片 |

颜色标识卡牌类型；卡面原类型栏现改为稀有度图片标牌（2026-09-15 用户要求）。普通、精良、稀有和特殊四张标牌（初始卡共用普通图片）见 `rarity/README.md`，中文字直接绘制在图片中。接入 `FormalUI.card_face()`（奖励、商店、图鉴）与 `CardView`（手牌、拖拽）；框与标牌不接收输入。

按用户最新示意图，统一使用 `scenes/ui/CardVisual.tscn`：同一个外框内从上到下为卡名栏、完整方形图片、稀有度图片栏，左上角保留六边形费用槽。图片与文字不重叠、不裁切；效果、类型和附魔说明在框外。手牌与拖拽卡为 136×212，大卡框高度为宽度加 76。此结构覆盖奖励、商店、图鉴（未发现卡隐藏内容）、牌堆浏览及点击详情，旧的方框/叠字布局不再使用。没有独立底板，费用普通显示数字，X 费显示 X，无法打出显示“—”。战利品中间区按原布局实测高度压缩到 60%，页头、奖励摘要和按钮尺寸不变；长内容整区滚动，描述本身不截断。

卡框尺寸以主体直边内沿为准，不以装饰尖角包围盒为准。FormalUI.card_frame 按四种原图各自的内沿距离校准 NinePatch 偏移，统一到内容区四周 12px；图片、名称与类型的位置不随尖角改变。宝箱卡牌奖励也使用 CardVisual，显示尺寸为 224×300，描述在框外下方。
