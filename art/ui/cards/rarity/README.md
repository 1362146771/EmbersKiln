# 卡牌稀有度图片标牌

稀有度栏高度为 48px（原 24px 的两倍），卡牌整体增加 24px：手牌 136×212，大卡高度为宽度加 76；标题、费用及插画在卡内的位置和尺寸不变。手牌容器仅向上增加 24px 显示空间，旁边牌堆保持原位。

2026-09-15：按用户要求替换卡面原“攻击 / 技能 / 能力 / 状态”文字栏。文字直接绘制在透明 PNG 中，运行时使用 `RarityBadge` TextureRect，不叠加 Label。卡框继续表示类型，详情和大卡框外说明显示类型。

| 数据稀有度 | 图片 | 识别方式 |
|---|---|---|
| starter 初始 | RARITY_common.png | 与普通卡共用普通图片 |
| common 普通 | RARITY_common.png | 铁灰、单层边框、铆钉 |
| uncommon 精良 | RARITY_uncommon.png | 蓝釉、银边、菱形端饰 |
| rare 稀有 | RARITY_rare.png | 琥珀金边、冠状角饰、炉火宝石 |
| special 特殊 | RARITY_special.png | 灰紫、缺口陶片；不表示高于稀有 |

PNG 保留生成器输出和透明通道；同名小写 `.tres` 为 AtlasTexture，仅限定标牌显示区域以排除透明留白，不改绘图内容。`FormalUI.RARITY_BADGES` 从真实 CardData.rarity 选择图片；未发现卡隐藏标牌。手牌、拖拽卡、详情、牌库、奖励、商店、图鉴和宝箱共用 `CardVisual.tscn`。

## 生成规范

使用内置 image_gen，逐张生成独立透明图片。共用提示：横向窑炉地牢 UI 标牌、粗墨黑轮廓、二分明暗、低饱和金属与陶釉、少量大形状；仅准确绘制“普通 / 精良 / 稀有 / 特殊”对应两个汉字，文字占标牌主体，不加旁注。分别使用上表材质与装饰。避免霓虹、写实渲染、密集花纹及背景。颜色和端饰共同表达层级，使缩小后仍可识别。初始卡复用普通图片，不单独生成或显示“初始”标牌。
