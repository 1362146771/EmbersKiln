# 窑口镇建筑院落近景

五栋功能建筑，每栋 0、1、2、3 级，共 20 张 1536×1024 高清原图；游戏使用 `runtime/` 下的 1024×683 PNG（Lanczos 缩小），用于点击建筑后显示的详情场景。已接入 `scenes/town/Town.tscn`，映射由 `data/town_visuals.json` 管理；仅异步加载选中建筑的同级院落，按原比例整图显示。运行验证入口为 `scenes/verify/TownVisualCapture.tscn`。

## 当前构图与人物要求

采用院门内侧稍高的斜角近景，同时看见建筑、院子和开放作业区。每栋各级保持同一构图与主要设备位置，适合等级切换对照。前景院墙和建筑上缘属于场景构图的一部分，接入时优先整图等比显示，避免再次裁切人物或工具。

玩家使用 `art/player/SPR_Player_Tannaro.png` 的白陶面具、深发、灰衣与蓝灰围裙形象，在院中手持工具和两名工人共同劳动。玩家不是旁观者。0 级表现共同清理和修缮，1–3 级表现设施生产或维护。

| 建筑 ID | 名称 | 玩家正常劳动动作 |
|---|---|---|
| hearth | 炉心 | 用短柄铲整理燃料 |
| card_mold_workshop | 牌模工坊 | 用木刮刀整平牌模中的陶泥 |
| relic_shelf | 遗珍架 | 用软刷清理陶器 |
| glaze_apothecary | 药釉坊 | 用长木桨搅拌釉料 |
| bellows_station | 风箱台 | 手握木柄杠杆操作风箱 |

## 等级美术

- 0 级：屋顶缺板、院墙与铺地破损、设备待修，炉火熄灭，人物手持工具清理与修缮。
- 1 级：基础木构与木板屋顶修复，恢复作业，院落仍较朴素。
- 2 级：白灰砖石墙、黑色弧瓦、灰石基础；建筑木构与设备不包铁皮，保留原木榫接。手持工具、人物护腕、陈列钟斧保持其材质。
- 3 级：延续白墙黑瓦，加入铆钉铁皮加固、完整屋脊及更成熟的设施设备，院落维护更整齐。

风格沿用当前外景的暖色手绘色块和细深色轮廓。图片不绘制 UI、名称和等级文字。全场景为不透明图，不能当作镇貌上的透明建筑层使用。

## 文件

- `{建筑ID}/{建筑ID}_interior_level_{等级}.png`：最终原尺寸图，直接复制 image_gen 输出，未重绘或压缩。
- `preview/{建筑ID}_levels.jpg`：每栋 2×2 等级对照，左上 0、右上 1、左下 2、右下 3。
- `preview/all_interior_levels.jpg`：五栋全套对照，按行排列建筑，按列排列等级 0–3。
- `manifest.json`：当前文件、尺寸、哈希清单。
- `source_manifest.json`：当前来源与内置 image_gen 提示词、参考图；被替代的室内/旁观构图不纳入交付。
- `town_interiors_levels_0-3.zip`：整套原图、对照图与清单。

`export_assets.py` 仅复制并校验原图、拼接预览和打包。全部创作由内置 image_gen 完成。本套美术等级不修改玩法等级或数值。

运行版本由 `python art/ui/town/interior_levels/build_runtime.py` 从高清原图重建。`data/town_visuals.json` 和局前准备场景均引用 `runtime/`；原图与来源清单保留。
