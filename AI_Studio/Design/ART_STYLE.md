# ART_STYLE.md — 美术风格（v3，暗黑地牢手绘漫画风）

> **版本变更**：v2「轻量化暗黑地牢风」→ v3「暗黑地牢手绘漫画风（Darkest Cel）」。
> 风格基线锚定参考图 `art/_ref/REF_style_darkest_cel.png`（已入库）：粗黑勾边 + 平涂二分阴影 + 去饱和色板 + 写实漫画比例。
> 相比 v2：比例更写实（4~5 头身 → 5~6 头身）、装备细节更重（铆钉/层叠甲片/束带）、色板从"古铜暖褐"转向"板岩蓝灰 + 橄榄绿 + 褐灰"的冷中性基调。
> 本文为强约束文件，Programmer / Art / Designer 在涉及美术决策时必须以本文件为准。

---

## 1. 风格定位（v3 与历史版本的差异）

| 维度 | v1（弃用） | v2（弃用） | **v3（当前）** |
|------|-----------|-----------|----------------|
| 整体调性 | 明亮扁平卡通 | 轻量暗黑地牢、古铜暖褐 | **暗黑地牢手绘漫画：冷中性 + 厚重装备 + 手绘笔触** |
| 线条 | 无描边 / 平涂 | 粗黑勾边（统一线宽） | **粗黑勾边（统一线宽）+ 内部结构线（甲片缝、束带、褶皱）** |
| 配色 | 奶油白 / 暖橙 / 青绿 | 古铜 / 赭褐 / 钢灰 + 锈红琥珀 | **板岩蓝灰 / 铁灰 / 褐灰 / 橄榄绿主导 + 暗赭红唯一角色点缀** |
| 质感 | 平涂 + 假阴影 | 平涂 + 二分阴影 | **平涂 + 明确二分阴影 + 装备材质三分类（金属/皮革/布料），甲片层叠感** |
| 角色比例 | Q 版 2~3 头身 | 中比例 4~5 头身 | **写实漫画比例 5~6 头身（参考图两名角色均为 5.5 头身左右）** |
| 装备细节 | 简化 | 铆钉 + 束带 | **层叠甲片、护肩铆钉、束带扣具、眼罩/伤痕等辨识度细节（少而准）** |
| 情绪 | 冒险、轻松 | 地牢冒险、严肃但可读 | **冷峻、坚毅、地牢探索的疲惫感；不血腥、不恐怖** |
| 敌我区分 | 玩家暖色 / 敌人冷色 | 靠装备/体型/姿态/UI | **继承 v2：统一中性色调，靠「装备完整度 + 体型 + 姿态 + UI 标识」区分** |

### 1.1 设计意图（一句话）

> 画面像一本手绘暗黑漫画：粗黑线、灰扑扑的铁与皮革、压低的饱和度，
> 玩家从笔触和比例就能感到"这是一趟不好走的地牢"，但看不到血腥与恐怖元素。

### 1.2 与《Darkest Dungeon》原作的差异（我们不走原作的重口路线）

- 不做血迹飞溅、肢体残缺特写、精神崩溃表现；
- 不做画面做旧污渍、纸张纹理叠加；
- 保留：粗黑勾边、去饱和中性色、厚甲铆钉、二分阴影、写实漫画比例。

### 1.3 Reference 锚点（仅美术 Prompt 与自检使用，不外发）

- **主锚点**：`art/_ref/REF_style_darkest_cel.png`（本仓库已入库，v3 一切色板/比例/笔触以此图为准）。
- 次要参考：《Darkest Dungeon》角色立绘的构图与装备层次（仅构图，不取其脏污做旧）。
- 严禁参考：恐怖 / 血腥 / 写实照片 / Q 版萌系 / 高饱和二次元。

## 4. Palette（v3 调色板，取自参考图色板，必须严格落板）

### 4.1 主色板（8 色，所有角色必用；C2~C8 即参考图中部 7 枚色样）

| 编号 | 用途 | HEX | 备注 |
|------|------|-----|------|
| C1 墨黑 | 主勾边 / 最深阴影 / 文字框 | `#1B1612` | 不可作大面积底色 |
| C2 板岩蓝灰 | 金属甲片 / 裙甲 / 冷色布料 | `#3A4554` | **v3 新主色**，替代 v2 古铜的大面积地位 |
| C3 铁灰 | 金属主体 / 武器 / 皮革中调 | `#68665E` | |
| C4 褐灰 | 皮革 / 木头 / 布料中调 / 发色 | `#94826F` | |
| C5 肤粉 | 皮肤底 / 浅衬布 / 角色高光 | `#E0C1AC` | 角色高光一律用它，禁用纯白 |
| C6 暗赭红 | **唯一角色点缀**：束带、徽记、内衬 | `#7E504E` | 饱和度低，面积仍须控制 |
| C7 橄榄绿 | 布料 / 裙裾 / 破败织物 | `#35392C` | 偏暗，勿提亮 |
| C8 暗紫黑 | 深阴影补充 / 夜行部位 / 暗色发色 | `#332831` | 仅作阴影层与局部，不作主色 |

> 单张角色立绘 **C6 占比 ≤ 6%**。C6 是全身唯一"暖色"，超过即失去参考图的冷峻感。
> 皮肤以外的亮部用 C5 的浅变体或 C3 的浅变体，**严禁纯白**。

### 4.2 辅色（功能色，不进角色立绘主色板）

| 用途 | HEX | 用法 |
|------|-----|------|
| UI 文字 / 面板高光 | `#F2E8D5`（米白） | 仅 UI 文字与图标高光，角色立绘禁用 |
| 增益 / Buff 图标底 | `#3FA67A`（青绿） | 仅图标 |
| 减益 / Debuff 图标底 | `#7A3D6E`（暗紫） | 仅图标 |
| 血条 / 危险提示 | `#9B2C2C`（暗血红） | 非猩红 |
| 火焰 / 能量流动 | `#D9A441`（琥珀）→ C6 渐变 | 仅 VFX 与能量 UI |
| 暗影 / 毒 / 暗属性 | `#4A3C66`（暗靛） | 仅 VFX |

### 4.3 严禁使用的色（v3 黑名单）

- ❌ 鲜艳粉红 / 亮粉 / 高饱和二次元色
- ❌ 任何纯白 `#FFFFFF` 高光（角色用 C5，UI 用米白 `#F2E8D5`）
- ❌ v1 主导色：奶油白 `#FBF3E4`、暖橙 `#F0997B`、青绿 `#5DCAA5`、珊瑚 `#D85A30`、蓝 `#378ADD`
- ❌ v2 主导色大面积复用：古铜 / 赭褐暖底（v3 基调是冷中性，不是暖褐）
- ❌ Q 版粉彩 / 渐变色块
- ❌ 玩家与敌人**整体色温差异**（v1 旧规则，持续废止）

## 5. Outline / Shape（v3 规则）

### 5.1 勾边（强制）

- 角色立绘、敌人立绘、卡面插画 **必须** 有外轮廓，**统一线宽**：
  - 角色立绘：2~2.5 px（按 256×256 画布）
  - 卡面插画：1~1.5 px
  - UI 图标：1 px
- 勾边色仅用 **C1 墨黑 `#1B1612`**，**严禁** 用其他色替代。
- 内部结构线（甲片接缝、束带边缘、褶皱、五官）也用 C1，线宽 ≤ 主线 50%。
- 参考图特征：外轮廓线**略带手绘抖动感**（非机械直线），允许 5% 以内线宽自然变化；禁止矢量感十足的均匀贝塞尔线。

### 5.2 形与体积

- 平涂色块 + **明确二分阴影**（亮面 + 暗面两段，阴影边缘为硬边，不画半调渐变）。
- 阴影色 = 底色 + C1/C8 调和的暗变体；亮部 = 底色 + C5 调和的浅变体。
- 角色五官简化但明确：一双眼睛 + 一张嘴；用眼罩 / 伤痕 / 胡茬 / 束发等 1~2 个记忆点拉开辨识度（参考图：眼罩 + 白发束髻）。
- 头发为色块 + 少量 C1 发束辅助线，不逐根刻画。
- 装备必须画出**层叠感**：护肩压胸甲、甲片压裙甲、束带压布料——用 C1 接缝线交代叠压关系。

### 5.3 材质三分类

| 材质 | 表现 |
|------|------|
| 金属 | C2 板岩蓝灰 / C3 铁灰 + C1 阴影；铆钉用 C5 肤粉点；**不加反光高光** |
| 皮革 | C4 褐灰 + C6 暗赭红做束带/扣具；扣眼纹理用细短 C1 辅助线 |
| 布料 | C7 橄榄绿 / C2 板岩蓝灰大色块，少量 C1 褶皱线 |

## 6. Scale Rules

- 玩家为标准尺寸 1.0；普通敌人 0.85~1.05；精英 1.25~1.5；Boss 1.6~2.0。
- 手牌卡面在移动端最小可读宽度 ≥ 120px。
- UI 文字最小 20px（手机基准 720×1280），标题 32px+，弹窗标题 56px+。
- 文字色默认 **米白 `#F2E8D5` 配 C1 墨黑描边 1 px**；深底面板文字 **不可用纯白**。

---

## 7. 敌我区分（继承 v2：禁用整体色温）

> 玩家与敌人共用同一套 §4.1 色板，仅靠以下手段区分（同时启用 ≥ 3 种）：

| 手段 | 玩家 | 敌人 |
|------|------|------|
| **① 装备完整度** | 全身甲 / 完整武器 / 有徽记 | 甲破洞 / 武器原始 / 徽记污损 |
| **② 体型 silhouette** | 对称、均衡、人形 | 不对称、变异、肢解感 |
| **③ 姿态** | 双脚着地、重心低、持械戒备 | 攻击性站姿、前倾、肢体张扬 |
| **④ 战斗位置 + UI** | 屏幕左下居中，有完整 HP/能量/手牌 | 屏幕右侧敌方槽位，独立敌方 HP 条 |

### 7.1 状态反馈的色

- 玩家受到伤害：屏幕暗角 + 暗血红 `#9B2C2C` 飘字
- 玩家格挡成功：C3 铁灰盾闪 + 米白数字
- 敌人受击：C5 肤粉描边闪烁 + C6 暗赭红飘字

### 7.2 命名兼容

- 玩家素材命名仍用 `SPR_Player_*`；**禁止** 用 ColorTint / 整图蒙版调色强加"玩家色"。

## 9. Status / Relic Icons

- 小尺寸下保持辨识度，靠**轮廓**而非色块区分。
- 减益类图标统一加 C1 墨黑圆框；增益类图标加琥珀 `#D9A441` 圆框。
- 单色图标优先用 C3 铁灰填充 + C1 描边 1 px + C5 肤粉高光点。
- 同类图标风格必须 100% 一致（线宽、圆角半径、填充层数统一）。

---

## 10. VFX

- 信息优先：出牌闪一下、伤害飘字、格挡盾闪、死亡淡出。
- 不做全屏大特效；不做血迹飞溅。
- 颜色严格落板：火/燃 = 琥珀 `#D9A441` → C6 渐变；击 = C5 肤粉闪；护 = C3 铁灰盾；毒/暗 = 暗靛 `#4A3C66`。
- 粒子形状用简单几何（圆、三角、方），不用曲线烟雾。

## 12. Godot 导入

- 角色立绘/插画：`Filter Mode = Linear`，`Compress = VRAM`，生成 Mipmap = false。
- UI 图标 / 小尺寸图标：`Filter Mode = Linear`，`Compress = Lossless`。
- 透明背景 PNG；UI 面板 9-slice 切片。
- 角色立绘同时输出 PSD 源文件至 `art/_src/` 备份（不进版本控制或用 Git LFS）。
- 风格参考图统一存 `art/_ref/`，入库管理。
