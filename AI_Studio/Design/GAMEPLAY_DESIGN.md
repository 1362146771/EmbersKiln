# GAMEPLAY_DESIGN.md — 玩法设计（v1，战士单职业）

## 1. 核心循环

```
开局(发初始卡组/遗物)
  → 地图选择节点
  → 战斗(回合制)
      胜利 → 奖励(选卡/金币/遗物)
      失败 → 单局结束
  → 地图推进
  → … 重复 …
  → Boss 节点
  → 单局胜利
```

## 2. 战斗回合结构

**玩家回合**
1. 抽牌至手牌（默认抽 5）。
2. 能量恢复至上限（默认 3）。
3. 玩家出牌：点击/拖拽选目标 → 校验能量 → 结算 effects → 进弃牌堆（或消耗）。
4. 玩家点「结束回合」→ 进入敌人回合（**格挡保留**，用于抵挡敌人攻击，不在此处清空）。

**敌人回合**
1. 每个敌人按当前意图行动（攻击 / 防御 / 增益 / 减益）。
2. 状态结算（中毒扣血、易伤/虚弱 -1 回合）。
3. 敌人格挡清空 → 回到玩家回合，刷新敌人意图。

## 3. 出牌规则（Feature: 卡牌出牌）
- **Rule**：每回合能量恢复到上限；出牌消耗对应能量；能量不足无法出牌。
- **Play**：点击卡牌 → 校验能量 / 目标 → 执行 effects → 入弃牌堆。
- **Edge Cases**：能量不足禁止出牌并提示；手牌为空可正常结束；抽牌堆空则洗回弃牌堆；消耗（exhaust）卡不回弃牌堆。

## 4. 格挡与状态结算顺序
0. **格挡清空时机**：玩家格挡在「下一个玩家回合开始时」清零（敌人攻击时仍生效，用于抵挡）；敌人格挡在其自身回合开始时清零。这是与《杀戮尖塔》一致的正确行为 —— 格挡要能扛过敌人攻击才有意义。
1. 攻击伤害先减目标格挡，溢出部分扣 HP。
2. 易伤使受到伤害 ×1.5（向下取整）。
3. 虚弱使造成攻击伤害 ×0.75。
4. 力量使每次攻击 += 力量层数。
5. 敏捷使获得格挡 += 敏捷层数。
6. 中毒：回合开始失去层数 HP，层数 -1。
7. 防御姿态类 Power：回合开始自动获得格挡。

## 5. 地图与节点（3 幕串联：Act1 10 层 / Act2 9 层 / Act3 8 层，每幕 1 Boss）
节点类型与产出：
- **战斗 Combat**：普通敌人，奖励卡三选一 + 金币。
- **精英 Elite**：强敌，奖励遗物 + 卡 + 更多金币（v1 仅 1-2 个）。
- **事件 Event**：选择分支，后果随机。
- **商店 Shop**：购买 / 移除卡。
- **休息 Rest**：回血 30% 或 升级一张卡（v1 频率更高，降低难度）。
- **宝箱 Treasure**：直接获得遗物。
- **Boss**：终局强敌，胜利即单局通关。

轻量分支：每层 1-2 个节点，玩家在本层内选择下一节点；Boss 固定在最后一层。

## 6. 奖励 / 商店 / 休息 / 事件
- **奖励**：战斗后卡牌三选一（按稀有度权重）；金币直接入账；精英/Boss 额外给遗物。
- **商店**：卡牌 50/75/100 金；遗物 120/200 金；移除卡 75 金（价格见 BALANCE_TABLE）。
- **休息**：二选一，回血或升级。
- **事件**：2-3 选项，后果如 ±金币、获得/失去卡、获得状态。

## 7. 胜负条件
- **胜利**：击败 Boss。
- **失败**：玩家 HP ≤ 0，单局结束。

## 8. Build 方向（战士）
- **狂暴 Aggro**：堆力量 + 高伤攻击，速杀。
- **铁壁 Defense**：高格挡 + 反伤，拖后期。
- **控场 Control**：易伤 / 虚弱 / 中毒削弱敌人。
- **燃烧 Burn**：持续伤害叠加。
- **召主 Summoner**：铺场随从分担火力 / 持续输出；配「指挥 command」增益与召唤卡（详见 `SUMMON_SYSTEM_DESIGN.md`）。

## 9. 与 Programmer 交接示例（卡牌出牌）
- **Feature**：卡牌出牌系统
- **Rule**：能量恢复上限；出牌扣费；不足禁止。
- **Target**：选中手牌（攻击类需选敌）。
- **Data**：伤害/格挡/费用/效果来自 `CardData.effects`。
- **Expected**：出牌后能量减少、效果结算、卡入弃牌堆。
- **Edge Cases**：见第 3 节。
